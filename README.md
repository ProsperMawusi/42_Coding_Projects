# 42_Coding_Projects
This repository includes projects I worked on as a student of 42 Wolfsburg
## Projects

### Virtual_Machine_Project (Born2beRoot)
This project involved the creation and setup of a **virtual machine** with a focus on **security best practices**. The goal was to create a secure, well-configured server environment with a focus on:
- **Firewall configuration** to limit access.
- **SSH hardening** (e.g., changing default ports, disabling root login, and using SSH keys).
- **Partitioning** the disk and configuring the system for optimal security.

### Ft_GetNextLine
In this project, I wrote a program in C that can read a file **line by line**. The function implements its own logic for reading files, handling different types of input, and ensuring that it can efficiently handle multiple lines.

### Ft_Printf
For this project, I implemented my own version of the standard `printf` function, which is commonly used in C for output. The project allowed me to gain a deeper understanding of variadic functions, memory handling, and custom formatting. Notably, my version:
- Does not handle all edge cases of the original `printf` function.
- Supports a subset of formatting options (e.g., `%d`, `%s`, `%x`).
